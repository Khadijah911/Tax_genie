Tax Genie

AI-powered Nigerian Tax Assistant that answers questions on the new nigeria's tax laws and also has a calculator interface that helps calculate tax.The assistant was built with LangChain and Gradio.

## Features
chatbot for tax questions
Personal Income Tax calculator
Company tax status Calculator
Based on Nigeria Tax Act 2026

## Installation
```bash
pip install -r requirements.txt
```
## Usage

**Jupyter Notebook:**
```bash
jupyter notebook Tax_genie.ipynb
```
**Python Script:**
```bash
python tax_genie.py
```

## Requirements
Python 3.8+
OpenAI API key
Tax documents 

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Add your OpenAI API key
4. Add tax PDF documents to the project folder
5. Run the application

## Tech Stack
LangChain
OpenAI GPT-4
ChromaDB
Gradio

NOTE
This tool provides general information based on the Nigeria Tax Act 2026. Always consult with a qualified tax professional for specific advice.
